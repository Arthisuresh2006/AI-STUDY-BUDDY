# AI-STUDY-BUDDY
AI Study Buddy is an intelligent educational support system designed to help students learn, revise, and understand academic subjects more effectively. The system uses Artificial Intelligence to provide personalized study assistance based on the student’s learning needs.It can provide topic-wise questions, answers, explanations, summaries, and revision support.
The main purpose of the project is to make studying easier, more interactive, and organized. Instead of depending only on textbooks or searching through different websites, students can use the AI Study Buddy as a single platform for their learning activities. The system can help students identify important topics, practice questions, and improve their understanding.
